## The line

> "The fortune you seek is in the log file you cleared this morning."

One original fortune-cookie line for a software developer: the fortune
you went looking for was in the very log you wiped this morning — the
answer was in the evidence you destroyed. The twist rewards a second
read: the seeker is the one who cleared the trail.

## How it runs

`main.py` (pure standard library) writes the line to `/output/entry.txt`
and asserts the 1–120 character gate, no trailing newline.

```
python3 main.py
```
